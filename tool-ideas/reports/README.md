# Tool-scout reports

Weekly ranked digests, gathered by the tool-scout cloud routine. Each run lands as
`YYYY-MM-DD.md` here and as a pull request titled "Tool scout — <date>", so you get a GitHub
notification you can read from your phone, plus a Gmail draft if the connector is connected.

Each candidate has: what it is, source repo + ownership flag (owned / client-engagement), a
market read (competitors/gap), a build-vs-open-source-vs-sell recommendation with reasoning,
and source links.

The top picks each run are also appended to `../backlog.md`. Ownership flags carry through —
nothing here clears a client-engagement idea for extraction; you decide the rights question.

Nothing here is auto-published or auto-sent. You read it, pick what's worth acting on, and
ignore the rest.
