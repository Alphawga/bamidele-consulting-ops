# Daily rhythm

AlphaBrain is not a todo app. It is the memory of how you operate. This file defines the daily operating system that compounds the four non-negotiable habits: **move, publish, reach, read**.

## The four non-negotiables

| Habit | Why it compounds | Minimum viable version |
|-------|------------------|------------------------|
| **Move** | Exercise is the base layer of energy and judgment. | 20 minutes of anything: walk, run, gym, bodyweight. |
| **Publish** | Content is the asset that markets while you sleep. | One post to the chosen platform, even if short. |
| **Reach** | Outreach is the handle you turn for revenue. | 10 meaningful touches: DMs, emails, comments, calls. |
| **Read** | Reading is the input that upgrades your model. | One focused session from the current book. |

These four are the floor. They do not depend on mood or inspiration. Everything else is built on top of them.

## Daily log format

Each day gets a file at `core/daily/YYYY-MM-DD.md`. The log has four sections.

### 1. MITs (Most Important Tasks)

List the 3 to 6 things that, if completed, make the day a win. These should come from the weekly plan (Monday morning) and the 90-day priorities. Do not list more than six. If you have more than six, you do not have priorities.

```markdown
- [ ] MIT 1
- [ ] MIT 2
- [ ] MIT 3
```

### 2. Non-negotiables

Check each habit and jot one line about it. The jot is not a diary entry. It is data: what did you do, what got in the way, what to adjust tomorrow.

```markdown
- [ ] Move — 20 min walk. Rain delayed it until 6 p.m.; move it to 5:30 tomorrow.
- [ ] Publish — LinkedIn AM pillar. Draft felt flat; rewrite opening hook before posting next time.
- [ ] Reach — 7 DMs, 3 comments. Two replies booked calls for next week.
- [ ] Read — The Sovereign Individual, 25 pages. Key idea: the transition from geography to cryptography.
```

### 3. LAPS mini-dashboard

From the sales framework in `domains/business/knowledge/sales/daniel-priestley-25-years-of-sales-knowledge.md`. Track the weekly flow, not just daily busyness.

| Metric | Target | Today | Week so far |
|--------|--------|-------|-------------|
| Leads | 50/week |  |  |
| Appointments | 10/week |  |  |
| Presentations | 6/week |  |  |
| Sales | 2/week |  |  |

### 4. Evening reflection

Two lines only:

- **Win**: the one thing that moved the needle today.
- **Friction**: the one thing that slowed you down and the adjustment for tomorrow.

## Weekly rhythm

- **Monday morning**: set the 3 to 6 critical things for the week. Lock antlers with yourself if you have to.
- **Friday afternoon**: debrief. Did you move the needle? What did you leave on the table? What carries forward?
- **Sunday**: review the upcoming week. Confirm the reading target, the content plan, and the outreach slots.

## Compounding rules

1. **Do not miss twice.** Missing one day is noise. Missing two days is the start of a new pattern.
2. **Minimum viable is the floor, not the target.** On good days, do more. On bad days, do the minimum.
3. **The log is the source of truth.** If it is not in the log, it did not happen.
4. **Review the last 7 logs every Friday.** Patterns hide in plain sight when you see them together.

## How this ties to AlphaBrain

- Content ideas from reading go to `domains/business/content/backlog.md`.
- Sales outcomes go to `domains/business/progress/` as dated entries.
- Exercise insights go to `domains/fitness/` once that domain is filled in.
- Book distillation happens in `domains/business/knowledge/` or `domains/book-writing/knowledge/` depending on the topic.

This file is the master rhythm. Domain files are the memory of specific outcomes.
